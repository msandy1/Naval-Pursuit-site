Privacy Policy for Naval Pursuit

Last updated: November 2026

Welcome to Naval Pursuit. This Privacy Policy applies to the Naval Pursuit Android application and the Naval Pursuit web application (collectively, the "App"). We are committed to protecting your privacy and ensuring you understand what data is collected and how it is used.

1. Data Collection and Usage

Naval Pursuit is designed to be a lightweight, multiplayer game. The types of data collected are minimal:

  • Game Data: When you host or join a game sector, gameplay actions (such as ship placements, attacks, and chat messages) are transmitted over the internet to the game server you are connected to.
  • Server Logs: The game server runs via Podman Quadlet. Standard operational logs (which may include IP addresses and connection timestamps) are captured and stored in the host system's systemd journal for diagnostic and security purposes.
  • Device Identifiers (Push Notifications): If you use the Android app, it utilizes Firebase Cloud Messaging (FCM) to deliver game updates (such as when it is your turn or if combat has begun). To enable this, a Firebase Installation ID is generated and sent to the game server.
  • Analytics: The Android app includes Firebase Analytics to help us understand general usage and crash reports to improve the App. This data is aggregated and does not personally identify you.

2. Permissions (Android App)

The Android app requests the following permissions for core functionality:

  • Internet: Required to connect to multiplayer game servers.
  • Vibrate: Used to provide haptic feedback during gameplay (e.g., when a ship is hit).
  • Notifications: Required to notify you of turn updates and game events when the app is in the background.

3. Third-Party Services

The App uses Google Firebase for analytics and push notifications. Firebase may collect anonymous usage data and unique installation IDs to function. Please review Google's Privacy Policy for more information on how they handle this data.

4. Data Retention

Gameplay data is only held on the specific server hosting that game sector. We do not maintain a centralized database of user accounts or game histories. Notification tokens (Installation IDs) are discarded when a game concludes or you leave the sector. Server logs maintained in the systemd journal are stored temporarily and are routinely rotated out by the host operating system.

5. Children's Privacy

Naval Pursuit does not knowingly collect personally identifiable information from children under 13. If you believe a child has provided us with personal information, please contact us so it can be deleted.

6. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be posted on this page.

7. Contact Us

If you have any questions or concerns regarding this Privacy Policy, please contact the developer.
